# 02._.mock — ระบบสอบออนไลน์

**เว็บออนไลน์:** <https://08wxch.github.io/02._.mock/>

เว็บแอปพลิเคชันสำหรับทำข้อสอบออนไลน์แบบครบวงจร ตั้งแต่ครูสร้างชุดสอบ แจกรหัส 6 หลัก ไปจนถึงการตรวจคำตอบและประกาศผลให้นักเรียน

สร้างด้วย HTML, CSS และ JavaScript แบบไม่ต้องมี build step · ข้อมูลหลักซิงก์ผ่าน **Supabase** (Postgres + Auth + RLS) เพื่อให้ครูและนักเรียนใช้ร่วมกันได้หลายเครื่อง

## เปิดเว็บจริง

- GitHub Pages (ฟรี): <https://08wxch.github.io/02._.mock/>
- โค้ดต้นทาง: <https://github.com/08wxch/02._.mock>

- ฐานข้อมูลกลางคือ Supabase project `hqpbvxmrolxhuexzzxgo` (Free plan) — ไม่ต้องเปิดเซิร์ฟเวอร์เอง

## สถาปัตยกรรมคลาวด์

- Frontend: static ES Modules (โฟลเดอร์นี้)
- ฐานข้อมูล: Supabase project `hqpbvxmrolxhuexzzxgo`
- ตาราง: `app_state` (ข้อมูลกลาง), `attempts` (คำตอบแยกแถว), `profiles` (ผูกบัญชี Auth กับครู/นักเรียน), `credentials` (รหัสผ่านสำหรับหน้าจัดการครู — ครูเท่านั้น), `guest_sessions` (โหมดรหัสเข้าสอบ)
- Login ครู/นักเรียน: Supabase Auth ด้วยอีเมลสังเคราะห์ที่ผูกจากรหัส/ชื่อในตาราง `profiles`
- โหมดรหัสเข้าสอบ 6 หลัก: Supabase Anonymous Sign-in + RPC `claim_guest` แล้วจึงอ่าน/เขียนคำตอบได้เฉพาะชื่อที่เลือก
- RLS เปิดทุกตาราง: นักเรียนเห็นเฉพาะ attempt ของตนเอง; ครูเห็นของผู้เรียนในความดูแล; เฉพาะครูเขียน `app_state` ได้
- สคริปต์ฐานข้อมูลอยู่ใน `supabase/schema.sql`, `guest.sql`, `access.sql`, `credentials.sql`, `identity.sql`
- ภาพประกอบโจทย์เก็บใน Supabase Storage bucket `question-images` (public read, teacher upload) — ตั้งค่าด้วย `supabase/question-images.sql`

## บัญชีและการเปลี่ยนรหัสผ่าน

- การเพิ่มครู/นักเรียนในหน้าเว็บจะสร้างบัญชี Supabase Auth ให้อัตโนมัติผ่าน Edge Function `accounts` (ใช้ service role เฉพาะฝั่งเซิร์ฟเวอร์) บัญชีจะพร้อมเข้าสู่ระบบภายในไม่กี่วินาที
- การเปลี่ยนรหัสผ่านจากโปรไฟล์จะอัปเดตทั้ง `credentials` และรหัสผ่านจริงใน Supabase Auth
- ครูสามารถเปลี่ยนรหัสของนักเรียน/ครูในหน่วยงานเดียวกันได้; เจ้าของระบบเปลี่ยนได้ทุกหน่วยงาน
- ถ้า session ของแท็บเก่าถูก rotate Edge Function ยังตรวจ JWT ผ่าน RLS เพื่อให้การสร้างบัญชี/เปลี่ยนรหัสไม่ล้มเหลวจาก `session_not_found`

## ภาพประกอบโจทย์และ TikZ

- แต่ละข้อเพิ่มรูปภาพได้ 1 รูป (PNG / JPG / WebP) ผ่านช่อง “ภาพประกอบโจทย์” ในหน้าสร้าง/แก้ไขชุดสอบ
- ระบบย่อรูปให้ด้านยาวไม่เกิน 1800 px และจำกัดไฟล์หลังย่อไม่เกิน 5 MB ก่อนอัปโหลดขึ้น Supabase Storage
- รูปจะแสดงในตัวอย่างข้อสอบ หน้าทำข้อสอบ หน้าเฉลย และหน้าตรวจคำตอบ
- **TikZ ยังไม่ render โดยตรงในเว็บ** เพราะตัวแสดงสมการใช้ KaTeX ซึ่งรองรับสูตรคณิตศาสตร์ ไม่ใช่ LaTeX compiler เต็มรูปแบบ
- วิธีใช้ TikZ: เขียนใน Overleaf/TeX แล้ว export เป็น PNG (แนะนำความละเอียดสูง) จากนั้นอัปโหลดเป็นภาพประกอบข้อนั้น

## สิทธิ์การใช้งาน

### Wich Pitchon — เจ้าของระบบ (`02._.math`)
- เห็นชุดสอบ **ทุกชุดของทุกหน่วยงาน** รวมถึงฉบับร่าง และเห็นสถิติทุกชุดโดยไม่ต้องรอปิดสอบ
- สร้าง/แก้ไข/ลบ **หน่วยงาน** และกำหนดชื่อย่อ
- สร้าง เปลี่ยนชื่อ และลบ class ได้ทุกหน่วยงาน
- สร้างบัญชี **ครูผู้สอน** และ **ผู้จัดการ** พร้อมเลือกหน่วยงานและแก้รหัสเริ่มต้น
- คลิกนามบัตรครูเพื่อดูรหัสผ่าน แก้รหัสครู เปลี่ยนหน่วยงาน หรือลบบัญชีออกจากระบบ (ข้อมูลชุดสอบเดิมยังคงอยู่)
- จัดการชุดสอบได้ทุกชุด ตรวจ–ประกาศผลได้ทุกชุด และเลือกหน่วยงานเจ้าของชุดสอบได้
- เลือก **ผู้ตรวจคำตอบ** ของแต่ละชุดสอบได้จากหน้าภาพรวม ผู้ที่ได้รับมอบหมายจะเห็นคิวตรวจ ให้คะแนนได้ และได้รับการแจ้งเตือน แต่เปิด/ปิดหรือแก้ไขชุดสอบไม่ได้
- ในหน้าตรวจคำตอบและหัวชุดสอบมีปุ่ม **แจ้งเตือนครู** สำหรับส่งการแจ้งเตือนในกระดิ่งไปยังผู้ตรวจ เจ้าของชุดสอบ และผู้จัดการหน่วยงานที่เกี่ยวข้อง
- กรองนักเรียนและบุคลากรตามหน่วยงาน หรือดูทั้งหมด
- ดูหน้า **สถิติรวม** เลือกทั้งหมด/หน่วยงาน/class ดูการ์ดภาพรวม กราฟแนวโน้มคะแนนตามชุดสอบ การกระจายคะแนน และคะแนนเฉลี่ยราย class แล้วกดเข้าไปดูอันดับนักเรียน
- เปลี่ยน **ตำแหน่ง/บทบาท** ของครูหรือผู้จัดการได้จากนามบัตร รวมถึงตำแหน่งของ Wich เอง (ความเป็นเจ้าของระบบไม่เปลี่ยน)

### ครูท่านอื่น
- เห็นนักเรียนและบุคลากรในหน่วยงานของตนเอง โดยมี Wich อยู่ลำดับแรก ถัดมาคือผู้จัดการของหน่วยงาน แล้วจึงครูผู้สอน
- หากหน่วยงานมีสิทธิ์ **จัดการองค์กร (`manage_all`)** ครูจะเห็นข้อมูลของทุกหน่วยงานได้ **แต่เป็นแบบอ่านอย่างเดียว** ไม่สามารถจัดการข้ามหน่วยงานได้
- เพิ่มนักเรียนในหน่วยงานของตนเอง (เลือกหน่วยงานไม่ได้) และกำหนด class ที่มีอยู่
- เห็นเฉพาะชุดสอบที่อยู่ภายใต้หน่วยงานของตนเอง (ไม่เห็นชุดสอบของหน่วยงานอื่น) และเป็นไปตาม **โหมดการแชร์**
- สร้างชุดสอบของตนเอง (ฉบับร่าง / บันทึกให้ครูเห็น / เปิดสอบ) ภายใต้หน่วยงานของตนเอง และเลือกโหมดแชร์ตอนสร้างหรือแก้ไข
- ไม่สามารถสร้าง class หน่วยงาน หรือบัญชีครู/ผู้จัดการได้ แต่ดู **สถิติรวม** และแท็บสถิติของชุดสอบในหน่วยงานได้
- ได้รับแจ้งเตือน/เห็นคิวตรวจเฉพาะชุดสอบที่ตนเองสร้าง หรือชุดสอบที่มีเจ้าของเลือกให้เป็น **ผู้ตรวจคำตอบ** เท่านั้น ไม่ได้รับแจ้งเตือนชุดสอบของครูท่านอื่นโดยอัตโนมัติ
- เปิด “ข้อมูลบัญชีนักเรียน” ในหน่วยงานเดียวกันเพื่อดูหรือเปลี่ยนรหัสผ่านของนักเรียนได้ แต่แก้รหัสนักเรียนไม่ได้ (เฉพาะ Wich/ผู้จัดการ)
- แม้อยู่ในหน่วยงาน `manage_all` ครูจะสร้าง/แก้ไข/ย้าย/ลบหน่วยงาน บุคลากร หรือนักเรียนนอกหน่วยงานของตนไม่ได้ และไม่มีปุ่มจัดการองค์กร
- นามบัตรบุคลากรคนอื่นจะไม่แสดงรหัสผ่าน ส่วนนามบัตรของตนเองแสดงรหัสผ่านและเปลี่ยนรหัสได้

### ผู้จัดการ (`manager`)
- เป็นบัญชีที่ Wich สร้างให้ และสังกัดหนึ่งหน่วยงาน
- เห็นนักเรียน บุคลากร และชุดสอบ **ทุกชุดในหน่วยงานของตนเอง** รวมถึงสถิติทุกชุด
- **อ่านและตรวจคำตอบได้ทุกชุดในหน่วยงานของตนเอง** แม้ไม่ใช่ผู้สร้าง และมีปุ่ม **แจ้งเตือนครู** ในหน้าตรวจคำตอบ/หัวชุดสอบเพื่อเตือนผู้ที่มีหน้าที่ตรวจ
- สร้าง/แก้ไข/เปิด/ปิด/ประกาศผลชุดสอบของตนเองได้ และแก้ไขชุดสอบที่ตั้งค่าให้ครูท่านอื่นแก้ไขได้ แต่ไม่สามารถเปิด/ปิด/ลบชุดสอบของครูคนอื่น
- ดูรายชื่อครูและบุคลากรในหน่วยงานได้ แต่ **เพิ่ม/ลบ/แก้รหัสครู** ได้เฉพาะเมื่อหน่วยงานของตนมีสิทธิ์ **จัดการองค์กร (`manage_all`)** เท่านั้น
- ผู้จัดการในหน่วยงานที่ไม่มีสิทธิ์ `manage_all` จะเห็นข้อมูลทีมแบบอ่านอย่างเดียว แต่ยังอ่าน/ตรวจชุดสอบได้ตามปกติ
- จัดการหน่วยงาน/สร้างหน่วยงาน/ย้ายบุคลากรได้เฉพาะเมื่อหน่วยงานของตนมีสิทธิ์ **จัดการองค์กร (`manage_all`)** เท่านั้น
- **บัญชีที่มีบทบาทเป็นครู แม้อยู่ในหน่วยงาน `manage_all` จะดูข้อมูลได้แต่จัดการองค์กร บุคลากร หรือข้ามหน่วยงานไม่ได้** ต่างจากบัญชีผู้จัดการ
- เพิ่มนักเรียนในหน่วยงานของตนเอง และแก้ class ของนักเรียนในหน่วยงานได้
- ดู **สถิติรวม** โดยเลือกได้เฉพาะทั้งหมดหรือ class ในหน่วยงานของตนเอง
- เปลี่ยนรหัสผ่านของตนเองได้จากนามบัตรของตนเอง และแก้รหัสของตนเองได้ (ยกเว้นรหัส Wich)

### โหมดการแชร์ชุดสอบ
ทุกครูเลือกได้ตอนสร้าง/แก้ไขชุดสอบ

| โหมด | ครูต่างคนในหน่วยงาน | สถิติ |
| --- | --- | --- |
| ครูท่านอื่นแก้ไขไม่ได้ (`view`) | เปิดดูข้อมูลได้ แต่แก้ไขเนื้อหา/คำถามไม่ได้ | เห็นสถิติหลังปิดสอบ และหน้าสถิติไม่แสดงโจทย์/ตัวเลือก/เฉลย |
| ครูท่านอื่นแก้ไขได้ (`edit`) | เปิดแก้ไขเนื้อหา/คำถามได้ แต่เปลี่ยนสถานะ ลบ หรือจัดการผู้เข้าสอบไม่ได้ | เห็นสถิติได้ตลอด และหน้าสถิติไม่แสดงโจทย์/ตัวเลือก/เฉลย |

Wich เจ้าของระบบเห็นและจัดการได้ทุกชุดเสมอ ผู้จัดการเห็นและ **ตรวจคำตอบได้ทุกชุดในหน่วยงาน** และแก้ไขเนื้อหาตามโหมดแชร์เหมือนครู ส่วนการเปิด/ปิด/ลบชุดสอบยังเป็นของเจ้าของชุดสอบหรือ Wich

### สถานะชุดสอบ
| สถานะ | นักเรียน | ครูคนอื่นในหน่วยงาน | เจ้าของ / Wich |
| --- | --- | --- | --- |
| ฉบับร่าง | ไม่เห็น | ไม่เห็น | เห็นและแก้ไขได้ |
| บันทึกแล้ว | ยังเข้าสอบไม่ได้ | ตามโหมดแชร์ | แก้ไข/เปิดสอบได้ |
| กำลังเปิดสอบ | เข้าสอบได้ตามวันเวลา | ตามโหมดแชร์; ดูสถิติได้ | จัดการได้ |
| ปิดรับคำตอบ | เข้าสอบใหม่ไม่ได้ | ตามโหมดแชร์; ดูสถิติได้ | ตรวจ/ประกาศผลได้ |
| ประกาศผลแล้ว | ดูผลและเฉลยได้ | ตามโหมดแชร์; ดูสถิติได้ | ดู/แก้ไขได้ |

ทุกการ์ดชุดสอบและหน้าเปิดดูจะแสดง **ผู้สร้าง + หน่วยงาน** อย่างชัดเจน เพื่อให้รู้ว่าชุดสอบนั้นถูกสร้างมาจากใคร

## ฐานข้อมูล

ฟังก์ชัน `public_exam_by_code` ใน `supabase/public-exam.sql` ใช้ค้นหาห้องสอบจากรหัสบนหน้า login โดยไม่ต้องพึ่งข้อมูลเก่าในเครื่อง

## รูปแบบรหัสและรหัสผ่าน

- **ครูใหม่:** `TCH` + ชื่อย่อหน่วยงาน + ตัวเลข เช่น `TCHSAT01`
- **แก้รหัสครู:** Wich หรือผู้จัดการของหน่วยงานแก้ได้ 3–24 ตัว (A–Z, 0–9, จุด, ขีดกลาง, ขีดล่าง) และต้องไม่ซ้ำกับบัญชีที่ยังใช้งานอยู่; รหัสของ Wich แก้ไม่ได้
- **ผู้จัดการใหม่:** `MGR` + ชื่อย่อหน่วยงาน + ตัวเลข เช่น `MGRSAT01`
- **รหัสผ่านเริ่มต้นของครู/ผู้จัดการ:** `123456` (Wich แก้ไขตอนสร้างได้ และเจ้าของบัญชีเปลี่ยนเองได้ภายหลัง)
- **รหัสนักเรียนใหม่:** ชื่อย่อหน่วยงาน + เลข 4 หลัก เริ่มที่ `0001` เช่น `SAT0001`, `SAT0002`, … และเลื่อนอัตโนมัติหากซ้ำ หรือครูพิมพ์เองก็ได้
- **แก้รหัสนักเรียน:** Wich และผู้จัดการของหน่วยงานนั้นแก้ได้ 3–20 ตัว และต้องไม่ซ้ำกับนักเรียนคนอื่น
- **รหัสผ่านเริ่มต้นของนักเรียน:** `123456`; ครูแก้ได้ตอนสร้าง และนักเรียนเปลี่ยนเองได้ภายหลัง
- Wich ใช้รหัสพิเศษ `02._.math` (ไม่ขึ้นต้นด้วย `TCH`) ส่วนบัญชีเดิมอื่นยังใช้ `TCH002`; รหัสผ่านเริ่มต้นของนักเรียนคือ `123456`

## สิ่งที่ทำได้

### ฝั่งนักเรียน
- เข้าสอบด้วยรหัส 6 หลักหรือบัญชีนักเรียน โดยต้องเลือกชื่อแล้วกรอกรหัสผ่านของบัญชีนักเรียนคนนั้น (ค่าเริ่มต้น `123456`) รหัสเข้าสอบจะแสดงเฉพาะรายชื่อที่ได้รับสิทธิ์ในชุดสอบนั้น
- กดชื่อของตนเองที่มุมขวาบนเพื่อเปิดโปรไฟล์ เผยรหัสผ่าน และเปลี่ยนรหัสผ่านของตนเอง
- หน้าหลักแสดงชุดสอบที่เปิดอยู่และนักเรียนได้รับสิทธิ์ **ทุกชุด** พร้อมเวลาปิดรับและปุ่มเข้าสอบของแต่ละชุด
- การ์ดชุดสอบหลักพร้อมเวลาถอยหลัง และรายการ “ชุดสอบอื่นที่ทำได้” เมื่อครูเปิดมากกว่าหนึ่งชุด
- หน้าคำชี้แจงพร้อมข้อตกลงก่อนเริ่มสอบ
- ตัวเลือกแบบเต็มแถว รองรับปรนัย ถูก/ผิด เติมคำ และอัตนัย
- บันทึกคำตอบอัตโนมัติ ทำเครื่องหมายข้อไว้ทบทวน และกลับมาทำต่อได้
- ยืนยันก่อนส่ง พร้อมแจ้งข้อที่ยังไม่ได้ตอบ
- หมดเวลาระบบส่งคำตอบให้อัตโนมัติ
- หน้าส่งคำตอบสำเร็จไม่เปิดเผยคะแนน
- ดูผลสอบ/เฉลยหลังครูประกาศผล และดาวน์โหลด PDF ผ่านหน้าต่างพิมพ์

### ฝั่งครู
- แดชบอร์ดภาพรวม จำนวนคำตอบรอตรวจ และคำตอบล่าสุด (ขอบเขตตามสิทธิ์ของบัญชี)
- แถบข้างแสดง “กำลังเปิดสอบ” เฉพาะชุดสอบที่บัญชีนั้นสร้างเอง และแสดง “ยังไม่มีการทดสอบต่อไป” เมื่อไม่มี
- กดชื่อตนเองมุมซ้ายล่างเพื่อเปิดโปรไฟล์ เผยรหัสผ่าน และเปลี่ยนรหัสผ่าน
- ดูนามบัตรนักเรียน คะแนนเฉลี่ย รายการชุดสอบที่ได้รับมอบหมาย พร้อมสถานะ “ยังไม่ได้ส่ง” และเปิดดูผลรายข้อของนักเรียนคนนั้น
- จัดการหน่วยงาน สร้างบัญชีครู/ผู้จัดการ และกรองนักเรียน/บุคลากรตามหน่วยงาน (เฉพาะ Wich)
- เลือกสิทธิ์ครูท่านอื่นได้ 2 แบบ คือ “แก้ไขได้” หรือ “แก้ไขไม่ได้” โดยหน้าสถิติไม่แสดงโจทย์ ตัวเลือก หรือเฉลย เพื่อป้องกันการทุจริต
- หน้าสถิติไม่แสดงโจทย์ ตัวเลือก หรือเฉลยแก่ทุกคน และรายละเอียดคำตอบรายข้อของนักเรียนจะแสดงเฉพาะเจ้าของชุดสอบ ผู้จัดการ และผู้ตรวจคำตอบ
- สร้างชุดสอบวิชาคณิตศาสตร์ด้วยตัวแก้ไขคำถาม 4 ประเภท พร้อมตรวจสอบความถูกต้อง
- สลับลำดับข้อได้ด้วยปุ่ม ↑ / ↓ ในหัวข้อ โดยหมายเลขและลำดับจะอัปเดตทันที
- คัดลอกข้อสอบจากชุดที่บันทึกไว้แล้วมาใส่ในชุดใหม่ได้ เลือกได้ทั้งบางข้อหรือทั้งหมด โดยยังคงโจทย์ ตัวเลือก เฉลย และภาพประกอบ
- กำหนด **วันเริ่มสอบ** และ **วันปิดสอบ** แยกจากกันด้วย date/time picker
- บันทึกเป็นฉบับร่าง, บันทึกให้ครูในหน่วยงานเห็น หรือบันทึกและเปิดสอบได้ในขั้นตอนเดียว
- เลือกผู้เข้าสอบเป็นรายคนหรือทั้ง class ก่อนเปิดสอบ และแก้ไขรายชื่อผู้เข้าสอบภายหลังได้
- แก้ไขชุดสอบที่สร้างแล้วได้ โดยรักษารหัสสอบ เจ้าของเดิม และประวัติคำตอบเดิมไว้
- พรีวิวข้อสอบในมุมมองนักเรียนก่อนเปิดสอบได้ เฉพาะเจ้าของชุดสอบหรือครูที่ได้รับสิทธิ์แก้ไข และการเลือกคำตอบในโหมดพรีวิวจะไม่ถูกบันทึก
- ลบชุดสอบ พร้อมคำตอบและประกาศที่เกี่ยวข้อง (เฉพาะเจ้าของหรือ Wich)
- ใส่สมการ LaTeX ในโจทย์ ตัวเลือก เฉลย และคำอธิบาย พร้อมตัวอย่างที่เรนเดอร์สด
- จัดการ class (เฉพาะ Wich): เพิ่ม เปลี่ยนชื่อ ลบ class ที่ว่าง และกำหนดให้นักเรียนอยู่ได้หลาย class
- เพิ่มนักเรียนพร้อมรหัสที่ระบบสร้างให้ หรือแก้ไขรหัสเอง และเลือกได้หลาย class
- เปิด/ปิดห้องสอบ และคัดลอกรหัสหรือลิงก์เข้าสอบ
- จัดการทะเบียนนักเรียน เลือกได้หลาย class ทั้งตอนเพิ่มและแก้ไขภายหลัง (ลบรายชื่อได้เฉพาะ Wich)
- ดูรายชื่อผู้เข้าสอบ กรองตามสถานะ เตือนนักเรียน และบังคับส่งคำตอบ
- ตรวจคำตอบรายคน ให้คะแนนข้ออัตนัย เขียนความคิดเห็น และปรับคะแนนรวม
- ตรวจคำตอบตามข้อ (grading queue) ข้ามนักเรียน
- ประกาศผล พร้อมเลือกแสดง/ซ่อนคะแนน เฉลย และอันดับ
- การแจ้งเตือน “ประกาศผลสอบแล้ว” จะหายไปเมื่อเปิดดูผลสอบที่ประกาศแล้ว
- สถิติรายข้อ คะแนนเฉลี่ย การกระจายคะแนน อันดับในห้อง
- ส่งออก Excel และพิมพ์รายงาน
